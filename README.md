# 🎨 Manipulador de Cores com DOM

Esse projeto foi criado para treinar **manipulação de DOM (Document Object Model)** usando **HTML**, **CSS** e **JavaScript** puros. Ele permite que o usuário digite uma cor em formato RGB e mude a cor de uma caixa na tela com apenas um clique.

## ✨ Funcionalidades

- Input para digitar a cor no formato `rgb(r, g, b)`
- Um botão estilizado que aplica a cor digitada à caixa
- Manipulação dinâmica de estilos com `style.backgroundColor`
- Treinando uso de:
  - `addEventListener`
  - `getElementById`
  - Estilização com classes
  - Manipulação de valores do input

## 💡 Objetivo

Esse sistema foi desenvolvido para praticar **JavaScript na prática**, focando no uso do DOM. Ele ajuda a entender como capturar eventos, manipular elementos da página e aplicar estilos com base na interação do usuário.

## 🛠 Tecnologias

- HTML5
- CSS3
- JavaScript puro (sem frameworks)
